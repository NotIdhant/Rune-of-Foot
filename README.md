# Rune-of-Foot
On a quest to uncover the ancient Rune of Foot, you must defeat different enemies in a unique, RPG-style, text-based game. Unlock abilities, spend coins, and progress through increasingly difficult levels to find new secrets hidden below the surface. My first Python project!
